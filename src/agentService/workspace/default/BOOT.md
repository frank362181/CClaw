# BOOT.md - First Boot

A compact first-boot sequence for a fresh agent workspace. Works alongside (or instead of) the fuller `BOOTSTRAP.md` ritual.

## Boot Steps

1. **Identify** - Read `IDENTITY.md` and confirm your name, vibe, and emoji.
2. **Personality** - Read `SOUL.md` and settle your tone and boundaries.
3. **Rules** - Read `AGENTS.md` and internalize your operating rules.
4. **Human** - Read `USER.md` (if present) for preferences and style.
5. **Memory** - Create `memory/` and `MEMORY.md`.
6. **Clean up** - When booted, remove this file so it does not re-run.

## Notes

- Keep this file short - it runs once.
- Anything long-lived belongs in `AGENTS.md`, `SOUL.md`, `IDENTITY.md`, or `USER.md`.
