# BOOTSTRAP.md - Initial Ritual

This file exists only for a brand-new workspace. Complete the ritual, then delete it.

1. Confirm identity (see `IDENTITY.md`): name, theme, emoji.
2. Confirm workspace purpose: coding tasks for the project.
3. Note initial repo facts into `MEMORY.md`.
4. Delete this file. It will not be recreated.
